## Use the file manager

Open **Files** on your server. Use **Upload** for files, **Upload folder** for directories, **New file** or **New folder** to create items, and **Code editor** to edit text files. Select a folder to open it. The search field searches the current folder.

Stop the server before replacing a world, plugin, mod, or configuration file that the game might write while running. Create a [backup](/backups) first.

## Connect with SFTP

SFTP is useful for larger transfers or many files at once.

1. Open **Settings** and find the **SFTP** section.
2. Copy the **Address** and **Username** shown for your server.
3. In an SFTP client such as FileZilla or Cyberduck, enter the host and port from the displayed address, your SFTP username, and your panel sign-in password.
4. Connect and transfer files into the appropriate server folder.

The SFTP address and username are server specific. Copy them from your own panel instead of using values from another server. Do not share your password or save it in a shared client profile.

<Tip>If you delete a file by mistake, check **Recycle Bin** for a recovery option. Keep separate backups for changes you cannot afford to lose.</Tip>
