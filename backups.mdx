---
title: "Create and restore backups"
description: "Protect your files before imports, modpack installs, and major changes."
---

Open **Backups** on your server to see existing backups and the number of backup slots available for that server.

## Create a backup

1. Select **New backup**.
2. Complete the options shown in the panel and start the backup.
3. Wait until its status shows that it is complete before making changes.

Create a backup before installing a modpack, importing from another host, changing server software, or replacing a world. If the server has no free backup slots, check which backups you still need before removing any.

## Restore a backup

Choose a completed backup in **Backups** and use its restore action. Restoring replaces current server files with the saved version. If you may need the current state later, make another backup or download the important files first.

<Warning>A backup stored in the panel is not a substitute for a copy you control outside the server. Download important backups when long-term retention matters.</Warning>
