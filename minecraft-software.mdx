---
title: "Choose Minecraft server software"
description: "Install a server type and version from the panel."
---

Open **MC Utils** → **Version**. Select the server software, then choose a Minecraft version and build. The panel lists options including Vanilla, Paper, Fabric, Forge, NeoForge, Purpur, and Velocity. Availability depends on what the software publisher provides.

| Software | Typical use |
| --- | --- |
| Vanilla | Unmodified Minecraft server. |
| Paper or Purpur | Bukkit-style plugins and performance features. |
| Fabric | Fabric mods. |
| Forge or NeoForge | Mods built for that loader. |
| Velocity | Proxy connecting multiple backend servers. |

Before switching, make a [backup](/backups). Changing server types can make existing plugins, mods, or worlds incompatible. The **Version** page says the server is stopped before installation and left stopped afterward. Review the console when you start it again.

For a specific version of Minecraft, also check the **Startup** variables if your game template exposes them. A server update does not update player clients, mods, or plugins for you.
