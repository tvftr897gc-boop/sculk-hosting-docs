---
title: "Install plugins and mods"
description: "Use the right add-ons for your Minecraft server software."
---

Minecraft plugins and mods use different server types. Check **Version** first so you know which software your server runs.

## Plugins

Use **MC Utils** → **Plugins** on a compatible server such as Paper or Purpur. Follow the installer to choose a plugin version that supports your Minecraft version. You can also upload plugin `.jar` files into the `plugins` folder using **Files** or [SFTP](/files-and-sftp). Restart the server and check **Console** for load errors.

## Mods

Use a matching mod loader such as Fabric, Forge, or NeoForge before installing mods. Open **MC Utils** → **Mods** on a modded server, or upload compatible mod files into `mods`. If the page says there is no `/mods` folder, the selected server likely does not use a mod loader. Many mods also need to be installed on each player's client.

<Warning>Do not install files from sources you do not trust. Back up your server before adding or updating multiple add-ons, and check each add-on's version and dependencies.</Warning>
