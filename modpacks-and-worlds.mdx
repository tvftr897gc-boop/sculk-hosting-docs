## Modpacks

Open **MC Utils** → **Modpacks** to search CurseForge, Modrinth, or Feed the Beast. Select a pack and follow the panel's installer. A modpack writes into the server root and can overwrite files with matching names. The installer may also change the startup command to run the pack. Make a [backup](/backups) before installing one, especially on a server with an existing world.

Players often need the same modpack installed on their own computers. Follow the pack author's client instructions.

## Worlds and maps

Open **MC Utils** → **Worlds** to browse CurseForge maps. Choose a compatible map and follow its install flow. If you are bringing your own world, upload its folder with **Files** or [SFTP](/files-and-sftp) while the server is stopped. Check the world folder name and the `level-name` setting in `server.properties` before starting.

The **World Viewer** is a separate panel section for viewing world data when supported. For game settings such as difficulty or view distance, use **MC Utils** → **Properties**, save your changes, and restart when required.
