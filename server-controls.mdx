---
title: "Server controls and console"
description: "Start, stop, restart, and monitor your server."
---

Open a server from the [panel dashboard](https://panel.sculkhosting.com). **Overview** shows its status, uptime, address, node, and CPU, memory, network, and disk readings. The address is also available in the header on other server pages.

| Control | What it does |
| --- | --- |
| **Start** | Starts an offline server. |
| **Restart** | Stops and starts the server. Use this after changes that require a restart. |
| **Stop** | Requests a normal shutdown so the game can save. |
| **Kill** | Forces the process to stop. Use this only if normal shutdown is stuck. |

## Use the console

Open **Console** to watch startup messages and game output. Enter a server command in the command field and press Enter. The console also has **All**, **Warnings**, and **Errors** filters and command history.

Console commands usually omit the `/` that you type in Minecraft chat. Confirm the syntax for your game or plugin before running a command. Never share logs without checking them for addresses, tokens, or other private information.

## Read resource usage

The graphs on **Overview** show recent CPU and memory usage. A brief spike during startup is normal. If the server repeatedly runs out of memory or crashes, check **Console** for the actual error and review recent mods, plugins, or settings changes.
