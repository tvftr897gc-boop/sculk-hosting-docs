# Sculk Hosting documentation

This repository contains customer-facing Mintlify documentation for the Sculk Hosting panel. Pages are MDX files with YAML frontmatter. Navigation and branding live in `docs.json`.

Use active voice, second person, and concise steps. Use sentence case headings, bold exact panel labels, and code formatting for paths, commands, and file names. Write examples with fictional addresses and no secrets. Document controls that are visible to a customer on the relevant server type. Warn before any operation that overwrites files, changes software, or restores data. Use the panel as the source of truth for exact UI wording.

Check navigation and internal links whenever adding or renaming pages. Preview with `npx mint dev` when the CLI is available.
