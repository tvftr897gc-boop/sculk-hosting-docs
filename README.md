# Sculk Hosting documentation

Customer guides for the Sculk Hosting server panel, built with Mintlify.

## Edit and preview

Pages are MDX files in this repository. Navigation, branding, and panel links live in `docs.json`. Run `npx mint dev` from the repository root to preview locally, then open the URL shown by the CLI.

Keep instructions tied to controls available in the customer panel. Check a feature in the panel before documenting its exact behavior. Use second person, concise steps, and bold UI labels. Avoid example credentials, private addresses, and customer data.

The Mintlify deployment is connected to the default branch. Review changes in a pull request before merging them into `main`.
