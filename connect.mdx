---
title: "Connect to a Minecraft server"
description: "Find your server address and join from Minecraft Java Edition."
---

1. In the [Sculk Hosting panel](https://panel.sculkhosting.com), select your Minecraft server.
2. In **Overview**, copy the address shown under **Hostname**. You can also use the copy button in the server header.
3. Open Minecraft Java Edition with a game version compatible with your server.
4. Select **Multiplayer**, then **Add Server** or **Direct Connection**.
5. Paste the address into **Server Address** and join.

The address can include a port, such as `example.com:25566`. Keep the port if it is shown. You do not need to add `:25565` when using the default Minecraft Java port.

## If you cannot connect

- Check **Console** to see whether the server finished starting. A running container can still be loading the game.
- Confirm that your client version matches the server version under **Version**. A modded server may also require the same loader and client mods.
- Copy the address again from **Overview**. The address used for SFTP in **Settings** is for file transfers, not joining the game.
- If the console shows an error, see [Get help](/support).
