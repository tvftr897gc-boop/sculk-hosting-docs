---
title: "Start your server"
description: "Sign in, find your server, and check that it is ready to use."
---

<Steps>
  <Step title="Open the panel">
    Sign in at [panel.sculkhosting.com](https://panel.sculkhosting.com). Your dashboard lists the servers you can access. Select **Manage** on the server you want to use.
  </Step>
  <Step title="Check its status">
    Open **Overview** to see the current status, address, CPU, memory, and disk usage. If the server is offline, select **Start**.
  </Step>
  <Step title="Watch the console">
    Open **Console** and wait for the game to finish starting. If startup fails, check the latest error in the console before changing files or settings.
  </Step>
  <Step title="Connect">
    Copy the address from the server header or **Overview**. For Minecraft Java Edition, follow [Connect to your server](/connect).
  </Step>
</Steps>

<Tip>Server controls appear in the header throughout the panel. **Restart** stops and starts the server. Use **Stop** before editing files that the game writes while running.</Tip>
